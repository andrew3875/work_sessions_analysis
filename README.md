# work_sessions_analysis
Jupyter Notebook для анализа временных меток активности. Преобразует список отметок времени в рабочие сессии и перерывы на основе заданного порога (15 минут). Выполняет сортировку, группировку событий, расчет длительности рабочих интервалов и пауз, а также формирует итоговую статистику по времени работы и отдыха с наглядным выводом в ячейках.

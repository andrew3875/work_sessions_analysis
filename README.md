# work_sessions_analysis
Jupyter Notebook для анализа временных меток активности. Преобразует список временных меток в рабочие сессии и перерывы на основе заданного порога (по умолчанию 15 минут). Выполняет сортировку, группировку меток, расчет длительности рабочих интервалов и пауз, формирует итоговую статистику по времени работы и отдыха с выводом в ячейке.
